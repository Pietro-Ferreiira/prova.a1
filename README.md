# Café & Grãos

Projeto da Unidade I - Desenvolvimento Front-End para Web (UNIPÊ).
Site de uma cafeteria fictícia, feito **apenas com HTML** (sem CSS e sem JavaScript).

## Tema
Loja de cafés com catálogo de produtos e formulário de pedido, com retirada na loja ou entrega.

## Páginas
| Arquivo | Conteúdo |
|---|---|
| `html/index.html` | Início: sobre a loja, perguntas frequentes, áudio de boas-vindas e meta de vendas |
| `html/produtos.html` | Produtos: tabela de preços com `colspan`, destaque e avaliação |
| `html/pedido.html` | Pedido: formulário avançado |

O menu de navegação está presente nas três páginas.

## Estrutura de pastas
```
loja-cafe-html/
├── README.md
├── html/    (páginas .html)
├── img/     (fachada-loja.jpg, cafe-especial.jpg)
├── audio/   (boas-vindas.mp3)
└── video/   (reservada para vídeos)
```

## Requisitos atendidos
- Tags semânticas: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
- Tabela 3x3 com `colspan`
- Formulário: `date`, `file`, `range`, `datalist`, `required`, `placeholder`
- `details` e `summary` nas 3 páginas e `figure` e `figcaption` em 2 páginas
- Marcação avançada: `abbr`, `mark`, `del`, `ins`, `blockquote`, `cite`, `progress`, `meter`
- `<audio>` local em `audio/boas-vindas.mp3`
- `<time datetime>` com a data da prova
- Comentário HTML explicando uma dificuldade (em `produtos.html`)

## Como abrir
Abra `html/index.html` no navegador.
